3. Web Caching & Proxy Servers

Edge Caching, 304 Validation & Reverse Proxy Load Balancing

Multi-Tier Web Caching

During admission registration, 90% of page weight comes from static files (University logo, campus banners, CSS, JavaScript libraries). Multi-tier caching prevents millions of unnecessary database and web server hits.

1. Browser Cache (Local Disk/RAM): Cache-Control: public, max-age=31536000, immutable → 0 ms instant load from memory.
2. Edge CDN Cache (Closest PoP): ETag: "64f9b-192a" / If-None-Match → 304 Not Modified (50-byte header, 0-byte payload).
3. Origin DB Server: Only dynamic queries (e.g. /api/v1/merit-rank) hit the origin database.

Reverse Proxy & Load Balancing

An Nginx Reverse Proxy sits in front of backend admission microservices to shield origin application servers from concurrency storms.

  • Load Balancing: Distributes applicants using Round-Robin, Least-Connections, or IP-Hash algorithms.
  • SSL/TLS Offloading: Handles expensive cryptographic handshakes at the edge so backend app nodes focus 100% CPU on admission business logic.
  • DDoS & Rate Limiting: Throttles automated scraping of admission merit lists.
  • Connection Pooling: Shields backend worker threads from slow cellular networks.
4. HTTP Protocols & State Management

Persistent HTTP, Stream Multiplexing & Cookie Optimization

Persistent HTTP vs Non-Persistent

In HTTP/1.0 (Non-Persistent), every single resource forces a separate TCP 3-way handshake (SYN → SYN-ACK → ACK) plus TLS negotiation and socket teardown (42 handshakes). HTTP/2 streams all assets concurrently over 1 single TCP connection.

Cookie Optimization & Session Security

By default, browsers attach domain cookies to every single request—including images, fonts, and scripts that don't need authentication!

The Upstream Bandwidth Multiplication Effect: 4 KB cookie × 50 assets × 25,000 students = 5.0 GB wasted header traffic!
Cookie-Free Static Domain: Serve static assets from static.college-cdn.com without sending cookies.
Minimal JWTs: Replace 4KB server session cookies with compact 180-byte tokens.
Security Flags: Enforce HttpOnly; Secure; SameSite=Strict against XSS and CSRF.
